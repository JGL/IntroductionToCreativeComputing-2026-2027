This first group session is one where we introduce ourselves to each other, after signing up to GitHub.
Before we start, I wanted to share a lovely analogy for what we are doing in this workshop: "we are setting up tools to get coding or get started with resources to find code, just like gathering materials you might need for other crafts like painting". I hope that's helpful!
Signing up to GitHub - the best place to find and share code
GitHub is a website that enables you to use Git to store, edit and share all your code with other developers around the world. Git is software for tracking changes to and sharing those changes with other programmers.Git is open source, while GitHub is owned by Microsoft. Both are free to use. Let's see what is on my GitHub. Github is the industry standard website for programmers - employers may look at your GitHub to see what kind of code you write and how you help others. It's the first place I go to find code to use in my own work.
But what does that really mean? What problem does Git (and GitHub) solve? Over to Daniel Shiffman for a great explanation. (BTW, Dan's whole playlist "Git and GitHub for Poets" is the one I'd recommend to learn more about them both). There are lots of great resources for learning creative code online and Dan's YouTube channel "The Coding Train" is the one that I recommend above all others.
Sign up to GitHub here: https://github.com/signup - please use a non university email address to do this, so you can keep logging in after you've graduated. Pick a username that you wouldn't be embarrassed to apply for a job with! I'll give you 5 minutes to do this.
